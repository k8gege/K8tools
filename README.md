# K8搞基工具包（2007–2013 年）
![https://github.com/k8gege/k8toolkit](https://github.com/k8gege/k8toolkit)
<p>
一份 2007–2013 年间的 K8 搞基工具包备份，学生时代攒下的各类工具：黑客工具、远控源码、网络渗透、逆向破解、病毒检测、系统加固、注册码、网吧破解等。<br>

工具最低兼容 Windows XP / Win7，部分工具在新版 Windows 上仍能运行。如今多半派不上用场了——AI 时代如此，就算没有 AI，不少工具也早已失效。更适合留给老旧系统环境备用，或者当作"考古研究"的素材。
</p>
